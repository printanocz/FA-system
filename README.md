# Splatno

Fakturační aplikace Adama Fujáka (adamfujak.cz), náhrada iDoklad.cz. Běží na `splatno.adamfujak.cz`.

- Zadání, architektura, roadmapa a pravidla: znalosti projektu „Fakturační Systém Adam“ na claude.ai (dokumenty 00–04).
- Vzhled: design systém „AF Fakturace“ a plátno „AF Fakturace — návrhy obrazovek“ (Claude Design). Název design systému zůstává, aplikace se jmenuje Splatno.
- Stack: Laravel 12 (PHP 8.4), Inertia + React + TypeScript, Tailwind v4, MySQL, hosting Gigaserver.

Nasazení a příprava serveru: [docs/DEPLOY.md](docs/DEPLOY.md).

Vývoj probíhá po úkolech T-XX ve větvích `t-XX-nazev` přes pull requesty do `main`.
